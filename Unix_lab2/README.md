# Лабораторная работа 2. Конкурентный контейнер

Работа состоит из Dockerfile и скрипта work.sh, написанного на POSIX Shell. Dockerfile создаёт образ с необходимой утилитой flock и запускает скрипт при старте контейнера.

Все контейнеры подключаются к одному тому Docker. Каждый контейнер один раз получает случайный идентификатор, после чего бесконечно повторяет цикл: создаёт файл, ждёт одну секунду, удаляет его и снова ждёт одну секунду.

Для нового файла выбирается первое свободное имя из последовательности 001, 002, 003 и так далее. В файл записываются идентификатор контейнера и порядковый номер файла, созданного этим контейнером. Имя файла может использоваться повторно после удаления, а порядковый номер внутри файла увеличивается.

Поиск свободного имени и создание файла выполняются под блокировкой flock на общем служебном файле .lock. Благодаря этому два контейнера не могут одновременно выбрать одно и то же свободное имя. Во время секундного ожидания блокировка не удерживается.

При завершении скрипт удаляет свой текущий файл. Работа проверена с одним, десятью и пятьюдесятью контейнерами.
