Монитор с поставщиком и потребителем Программа написана на C++ с использованием POSIX Threads (pthread). Поставщик раз в секунду создаёт событие и передаёт указатель на объект потребителю. Потребитель обрабатывает событие и освобождает память. Сообщения строго чередуются. Ожидание выполняется через условную переменную, без постоянного опроса состояния. После пяти событий оба потока завершаются, и программа выходит.
