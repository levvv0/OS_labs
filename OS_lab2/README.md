Сервер TCP/IP и обработка сигналов

Программа написана на C++17 для Linux/UNIX и использует POSIX-функцию pselect().
Она принимает подключения, оставляет открытым одного клиента, а остальные
подключения закрывает. При чтении данных выводит число полученных байтов.
Сигнал SIGHUP вызывает сообщение; Ctrl+C (SIGINT) завершает сервер.

Сборка:

    g++ -std=c++17 -Wall -Wextra -pedantic server.cpp -o server

Запуск (порт 9090 по умолчанию):

    ./server

Или указать порт:

    ./server 9091

В другом терминале можно подключиться командой:

    nc 127.0.0.1 9090

Введите текст и нажмите Enter. Сервер выведет число принятых байтов.
Повторный запуск nc создаст дополнительное соединение, которое сервер сразу закроет.
Для проверки сигнала возьмите PID из строки запуска сервера и выполните:

    kill -HUP PID

Подставьте число вместо PID. Сервер сообщит о SIGHUP и продолжит работу.
Для остановки нажмите Ctrl+C в терминале сервера.

При обычной работе сигнал SIGHUP заблокирован. pselect() атомарно снимает
блокировку на время ожидания и восстанавливает её при возврате. Обработчик
только устанавливает флаг; вывод выполняется в основном цикле.
