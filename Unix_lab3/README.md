Программа на C++17 ищет одинаковые файлы в указанном каталоге и его подкаталогах. Один файл из каждой группы остаётся исходным, а остальные имена заменяются жёсткими ссылками на него. Символические ссылки и другие объекты, не являющиеся обычными файлами, пропускаются.

Для каждого файла вычисляется 64-битный хэш FNV-1a. Если размер и хэш совпали, содержимое дополнительно сравнивается побайтово. Это защищает от ошибочного объединения разных файлов при совпадении хэша.

При замене сначала создаётся временная жёсткая ссылка рядом с дубликатом, затем она переименовывается в имя дубликата. Если создать ссылку не удалось, исходный дубликат остаётся на месте. Программа не запускает внешние утилиты.

Сборка

g++ -std=c++17 hardlink_dedup.cpp -o hardlink_dedup

Запуск

Программа принимает один аргумент — путь к каталогу:

./hardlink_dedup ./test_data

Она выводит выполненные замены, число проверенных файлов (Files checked) и число заменённых файлов (Files replaced). Повторный запуск не заменяет файлы, которые уже являются жёсткими ссылками друг на друга.

Проверить результат можно командой:

ls -li ./test_data

У имён, указывающих на один файл, совпадают номера inode в первом столбце. Жёсткие ссылки нельзя создавать между разными файловыми системами. После объединения изменение содержимого через одно имя будет видно через остальные имена этой группы.
