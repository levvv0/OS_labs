# Лабораторная работа: горизонтально масштабируемый сервис

Сервис подсчитывает слова в присланном тексте. Написан на Java 21 и Spring Boot. Состоит из HTTP-приложения `api`, брокера RabbitMQ и приложения `worker`. Работников можно запускать в нескольких одинаковых экземплярах; все они получают задачи из одной очереди, а RabbitMQ распределяет их между репликами.

`api` принимает текст, возвращает идентификатор задачи и отправляет сообщение в очередь `word-tasks`. Работник получает сообщение, считает слова, отправляет результат в `word-results`. `api` забирает результат и отдаёт его по идентификатору. В результате также указано, какой контейнер выполнил задачу.

Исходники двух приложений находятся в отдельных модулях `api` и `worker`. В каждом модуле один Java-пакет `lab`; стандартный каталог `src/main/java` нужен Maven.

## Запуск

Из каталога с `compose.yaml` запустить:

```sh
docker compose up -d --build
```

Эта команда собирает образы и запускает один API-контейнер, RabbitMQ и одного работника. Для трёх работников:

```sh
docker compose up -d --scale worker=3
```

Число после `=` — желаемое количество реплик. У `worker` нет фиксированного имени контейнера и опубликованного порта, поэтому его можно масштабировать.

## Проверка

Команды ниже вводятся в терминале Ubuntu, где работает Docker. Отправить задачу:

```sh
curl -X POST http://localhost:8080/tasks -H 'Content-Type: application/json' -d '{"text":"one two three"}'
```

В ответе будет `id` и статус `queued`. Подставить полученный `id` вместо `TASK_ID`:

```sh
curl http://localhost:8080/tasks/TASK_ID
```

После обработки придёт статус `done`, поле `wordCount` со значением `3` и поле `worker` с идентификатором обработавшего контейнера. Отправьте несколько задач, повторяя команду `curl -X POST`; результаты должны содержать разные значения `worker`. Каждая задача искусственно обрабатывается одну секунду, чтобы распределение было легче увидеть.

Посмотреть запущенные реплики:

```sh
docker compose ps
```

Посмотреть сообщения работников:

```sh
docker compose logs worker
```

Интерфейс RabbitMQ доступен на `http://localhost:15672` с логином `lab` и паролем `lab-password`. Порты 8080 и 15672 доступны только на самой машине с Docker.

Остановить сервис:

```sh
docker compose down
```

## Ограничение учебной версии

Статусы и результаты задач хранятся в памяти одного контейнера `api`. При его перезапуске ранее выданные идентификаторы перестанут находиться. Для лабораторной демонстрации достаточно одного `api` и нескольких реплик `worker`; для постоянного хранения результатов нужна база данных.
